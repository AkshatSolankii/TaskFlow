TaskFlow is a clean and easy-to-use Task Management Web App built using Python Flask and SQLite.
You can add tasks, edit them, delete them, and mark them as completed or pending.

Features

Add New Tasks

Edit Existing Tasks

Delete Tasks

Mark Tasks as Completed / Pending

Success & Error Messages

Clean Dashboard UI (based on client design)

Filter: All / Completed / Pending

UI Overview

Dashboard shows all tasks in a table

“+ Add Task” button to create new tasks

Status checkbox to mark complete

Completed tasks show with strikethrough

Add Task page includes:

Title

Description

Deadline

Priority (High / Medium / Low)

How to Run the Project
1 Clone the project
git clone https://github.com/AkshatSolankii/TaskFlow.git
cd TaskFlow

2 Run the app
python app.py

Open in browser:

http://127.0.0.1:5000
